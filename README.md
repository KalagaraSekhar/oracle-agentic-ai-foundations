# 📖 Documentation Standards

This repository follows several principles:

1. **Understand before documenting**
2. **Prefer original explanations over copied course text**
3. **Document hands-on implementation**
4. **Keep technical notes concise and structured**
5. **Record mistakes and lessons learned**
6. **Use diagrams where architecture is involved**
7. **Separate learning notes from implementation**
8. **Never expose credentials, API keys or secrets**

# 🔐 Security

No API keys, passwords, access tokens or private credentials should ever be committed to this repository.

